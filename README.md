# NEXORA Article

This repository contains the exported article and supporting static files for the NEXORA article project.

## Run locally

```bash
npm install
npm start
```

Then open the served page in your browser.

## Included files

- `d415d512-e2a4-4667-8779-dc1c90c94c8e.html` — article page
- `article.json` — article metadata
- `package.json` — project scripts and package metadata
- `.gitignore` — ignores local environment and dependency folders
